GitHub Copilot: Perfeito! Vamos configurar para você disparar via webhook e receber emails no Gmail.

## Setup Completo

### 1. Configurar Gmail para enviar emails

Primeiro, você precisa criar uma **senha de app** no Gmail:

1. Acesse: https://myaccount.google.com/apppasswords
2. Crie uma senha de app (escolha "Outro" e dê um nome tipo "ZeroClaw")
3. Copie a senha gerada (16 caracteres)

### 2. Configurar o ZeroClaw

Edite `~/.zeroclaw/config.toml` e adicione:

```toml
[channels_config.email]
smtp_host = "smtp.gmail.com"
smtp_port = 587
smtp_username = "edgar.segundo@gmail.com"
smtp_password = "xxxx xxxx xxxx xxxx"  # Cole a senha de app aqui
smtp_from = "edgar.segundo@gmail.com"

imap_host = "imap.gmail.com"
imap_port = 993
imap_username = "edgar.segundo@gmail.com"
imap_password = "xxxx xxxx xxxx xxxx"  # Mesma senha de app

allowed_senders = ["edgar.segundo@gmail.com"]

[browser]
enabled = true
allowed_domains = ["registro.br"]
backend = "agent_browser"

[heartbeat]
enabled = true
interval_minutes = 360  # A cada 6 horas
```

### 3. Iniciar o agent-browser (necessário para ler páginas web)

```bash
# Instalar agent-browser (se ainda não tiver)
npm install -g @agent-browser/agent-browser

# Iniciar o serviço
agent-browser --port 8000
```

### 4. Iniciar o daemon

```bash
zeroclaw daemon
```

### 5. Disparar a automação via webhook

```bash
curl -X POST http://localhost:3001/webhook \
  -H "Authorization: Bearer zc_SEU_TOKEN_AQUI" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Você é um agente de monitoramento de domínios. Sua tarefa: 1) Acesse https://registro.br/dominio/processo-de-liberacao/ usando a ferramenta browser. 2) Extraia todos os domínios e suas datas de liberação. 3) Se encontrar domínios com datas de liberação nos próximos 30 dias, envie um email para edgar.segundo@gmail.com com a lista completa de domínios e datas. 4) Salve na memória os domínios que você já notificou para evitar duplicatas. 5) A cada 6 horas, repita esse processo automaticamente. Execute essa tarefa AGORA e configure para repetir automaticamente."
  }'
```

### 6. Verificar que funcionou

O agente vai:
1. ✅ Acessar a página com a ferramenta `browser`
2. ✅ Extrair domínios e datas
3. ✅ Enviar email para você **imediatamente** se encontrar domínios
4. ✅ Salvar na memória os domínios notificados
5. ✅ Repetir a cada 6 horas automaticamente

### 7. Alternativa: HEARTBEAT.md (mais confiável)

Se você quiser garantir que a automação persiste mesmo após restart, crie:

```bash
cat > ~/.zeroclaw/workspace/HEARTBEAT.md << 'EOF'
# Tarefas Periódicas

## A cada 6 horas
1. Usar ferramenta `browser` para acessar https://registro.br/dominio/processo-de-liberacao/
2. Extrair todos os domínios e suas datas de liberação
3. Para cada domínio com data nos próximos 30 dias:
   - Verificar na memória se já foi notificado
   - Se não foi notificado:
     - Enviar email para edgar.segundo@gmail.com com nome do domínio e data
     - Salvar na memória: "notificado_dominio_[nome]" com valor "sim"
4. Registrar timestamp desta execução na memória
EOF
```

Reinicie o daemon:
```bash
zeroclaw daemon
```
